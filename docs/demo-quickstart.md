## 出现问题

- 页面打不开：启动 Docker Desktop，双击项目里的`启动演示.command`。
- MFA拒绝：等下一组验证码后再次执行code命令。
- 运营拒绝：确认owner账号和星河科技空间。
- 不要点击更新、重置演示数据或全设备退出；普通市场退出放最后。

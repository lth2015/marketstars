# 统一模型网关、Token 按量收费、供应商自动分账、图片上传

## 统一模型网关与 SDK
- 接口为 `POST /api/v1/models/messages`。接入应用用自己的 client 凭证代表租户调用模型，SDK 在 `src/sdk/marketstars.ts`（`MarketStarsClient.messages()`）。
- 每次调用的处理顺序：
  1. 校验租户当前是否有有效权益，以及应用是否被暂停。
  2. 检查月度用量上限。
  3. 调用模型。
  4. 按套餐单价记录用量。
- 模型：
  - 设置了 `ANTHROPIC_API_KEY` 时，用官方 `@anthropic-ai/sdk` 调用 Claude。默认模型 `claude-opus-5-5`，可选 `claude-sonnet-5-5`、`claude-haiku-5-5`，由 `MODEL_GATEWAY_DEFAULT_MODEL` 配置。
  - 调用时开启了服务端拒答回退（`fallbacks: "default"`）：模型拒答时，由服务端自动换用其他模型。
  - 没有设置 key 时使用确定性的 mock 模型，不访问外网。演示环境和 e2e 都是用 mock 跑的。
- 生产环境要放行 `api.anthropic.com` 的出站访问，key 放在 Secret Manager 的 `marketstars-anthropic-api-key`。
- 防重复计费：`(appId, request_id)` 唯一，同一请求重试返回 409，只计费一次。
- 限制：输入最多 2 万字符，`max_tokens` 最多 4096，每个租户可以自己设月度上限。

## Token 按量收费
- 套餐新增字段「AI 従量単価（日元 / 100 万 Token）」，可在运营套餐表单和开发者套餐提案中设置。修改后会生成新的价格版本。
- 每次调用的费用以千分之一日元为单位记录，并保存当时的单价快照。
- 合同详情页显示本月用量和预计费用，owner 可以设置月度上限（日元），达到上限后网关返回 429。
- 按日本时间的自然月结算。定时任务 `billUsage` 每月为上月用量生成一条 `kind=usage` 的账单，唯一约束保证不会重复生成：
  - 信用卡订阅：立即扣款。
  - 请求书払い：账单为未付状态，由运营在请求記録页确认收款。
- 演示数据：AI POPメーカー的スタンダード套餐单价为 ¥3,000 / 100 万 Token。

## 供应商自动分账
- 每个提供商有一个分配比例 `revenueShareBps`，默认 70% 归提供商，运营可以修改。
- 每月初由定时任务 `autoPayouts` 自动为上月生成结算单，运营也可以在 `/admin/payouts` 手动生成：
  - 收入：当月确认收款的账单，包括月费和 AI 按量费用。
  - 退款：当月发生的退款。
  - 平台手续费 = (收入 − 退款) × (1 − 分配比例)。给提供商的金额向下取整到日元。
- 已生成的结算单不会重新计算，生成之后才发生的退款计入下月。运营填写转账参考号后，结算单标为「已支付」。
- 开发者在 `/developer/earnings` 查看本月销售额、历史结算单，并登记收款账户。
- 未做：真实银行转账 / 支付服务商的分账 API、源泉徴収和适格请求书（インボイス）的税务处理，需要在上线前确认。

## 图片上传
- 开发者编辑页和运营应用编辑页都可以上传图标和截图，只接受 PNG / JPEG / WebP，每张不超过 2MB，截图最多 8 张。
- 文件类型按文件头判断，不信任扩展名；SVG 一律拒绝。
- 图片通过 `/api/assets/{id}` 提供，响应带 `nosniff`、`CSP sandbox` 和长期缓存。
- 演示环境把图片存在数据库里。生产环境建议改存 Cloud Storage，接口不变。

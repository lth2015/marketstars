# StarPay 合算請求（P1「与原服务合并收费」）

PRD §2 把「与原服务合并收费」列为 P1：首版独立记录申请、账单与收款确认；P1 再与 StarPay 的请求合并。本文说明合算请求的规则与实现。

## 流程
1. **连携**：空间 owner 在「請求・お支払い」输入 StarPay 加盟店番号（`SP` + 8 位）。MarketStars 调用 StarPay 加盟店 API 照合后保存 `StarpayLink`（一个加盟店只能连携一个空间）。
   - 目前用决定性的 mock 代替 API：格式正确即通过；**末尾为 9 的番号视为不存在**（用于演示错误）。
2. **申込**：已连携的空间在月额套餐的开通确认页多一个支付方式「StarPay の利用料と合算」。
   - 申込即开始利用，`paymentMode=starpay`，自动更新。
   - 每个周期生成一条 `BillingRecord(channel=starpay, status=due)`，即「合算請求待ち」。
   - 未连携的空间看不到该选项，伪造请求在服务端被拒绝（`no_starpay`）。
2b. **体验 / 免费套餐 → 付费**：已连携的空间在契约内容的「プランの変更」也可以选「StarPay 利用料と合算（すぐに切り替え）」，立即切换为付费（首期请求为合算請求待ち，自动更新）。这与银行卡的即时切换相同，不需要等待运营确认入金。
3. **自动更新**：定时任务 `renewDue` 中的 `renewStarpay`。
   - 到期前 24 小时内延长一个周期，并记录下一条合算请求待ち。
   - 条件更新加上请求的唯一约束保证幂等。
   - 解除连携后不再更新，周期结束后按正常规则到期。
4. **合算明细**（运营 `/admin/starpay`）：每月一份 `StarpayStatement`，状态为 `open`（可追加）→ `exported`（已输出 CSV，确定）→ `settled`（已回收）。
   - 生成时，按「预定登载月」载入未登载的合算请求。预定登载月默认是利用周期的开始月（JST）。如果该月的明细已输出或已回收，就顺延到之后第一个仍可追加的月份，所以之后才产生的请求不会滞留。
   - **第一次下载 CSV 即确定明细**，之后不再追加。交给 StarPay 的内容与回收确认的对象始终一致。
   - 生成时对明细行加 `FOR UPDATE` 锁，与 CSV 输出、回收确认同时发生时，也不会把请求混进已确定的明细。
   - CSV 中的加盟店番号取自**请求生成时**记录在 `BillingRecord.starpayMerchantId` 的值，之后更换连携也不会改变请求对象。
   - 时间为 JST；值中的换行会被去掉，以 `= + - @` 开头的值加 `'` 前缀，防止 CSV 注入。
5. **回收确认**：只能对已输出 CSV 的明细执行，且只能执行一次。
   - 运营输入 StarPay 的回收参照番号后，明细内的请求全部变为入金済み（`receiptRef = <参照番号>#<billingId>`），并发出 `payment.succeeded`。
   - 这些入金随后进入防篡改台帐和提供会社的精算。
   - 普通的「請求記録」页面不能单独对合算请求确认入金，以免与 StarPay 侧重复回收。

## 规则与边界
- 合算请求「先利用、后回收」：StarPay 已与加盟店有持续的请求关系，因此与请求书支付（运营确认入金后才开始）不同，申込即开始。这是 P1 的业务前提，正式上线前需与 StarPay 侧确认信用与未回收时的处理（停止利用的时点、催收）。
- 存在合算中的有料契约或未回收的合算请求时，不能解除连携，也不能改连其他加盟店。期末解约且请求回收后可以解除。解除操作锁定连携行后再检查。
- 降级为免费套餐时，支付方式恢复为请求书，免费契约不会阻止解除连携。
- 合算请求待ち属于未入金：账号注销申请的事前检查会把它列为需要先处理的事项。
- 合算契约在契约内容页不显示卡片自动更新的设置，更新由 StarPay 合算自动进行，停止请使用期末解约。

## 测试
`tests/e2e-p12.mjs`（8 项）：
- 连携：格式错误与不存在的番号被拒绝，可以解除连携；
- 合算申込：即时开始，首期请求为合算請求待ち；
- 未连携空间看不到该选项，伪造请求被服务端拒绝；
- 自动更新只执行一次；
- 运营生成明细 → CSV（含加盟店番号）→ 回收确认后全部入金済み，且不能重复确认；
- 合算中的契约存在时不能解除连携；
- 免费体验可以用 StarPay 合算立即转为付费（A07 的路径）；
- 免费套餐可以用 StarPay 合算升级；未连携时看不到该选项。
